# Look at the screen before calling UI work done

1. In `pra/`: `npm run dev` (background) and open the local URL with Playwright.
2. Visit the screen you changed at 1280 px and at 390 px wide. Take a screenshot of each.
3. Check: nothing overflows sideways, touch targets are at least 44 px on the narrow view,
   focus is visible when tabbing, the console has no errors.
4. For print work use the browser's print preview (A4 and 80 mm).
5. Stop the dev server. Describe what you saw; attach the screenshots' paths.
